Carousel

A carousel cycles through a sequence of content panels within a single compact section, usually displaying one or few at a time. Users navigate between slides using previous and next buttons or tabs.

Carousels can be used when one area of the page must showcase several related but independent items, such as presentation slides, images or cards. They are less suitable for primary content, since slides that are not currently visible are easily overlooked.

Accessibility Features

= Required = Recommended
  • Carousel controls must have descriptive labels or accessible names. They must convey that the buttons are used to navigate between slides
  • Carousel controls must be placed before the slides in the DOM order
  • Slides can be navigated using previous/next buttons or tabs. If tabs are used, appropriate attributes and keyboard interaction patterns are required. See the Tabs page for details
  • Feedback must be provided when the slide changes. This can be achieved, for example, using aria-live region. Note that the attribute must be turned off when the slide rotates automatically
  • If the carousel rotates automatically, a play/pause button must be available to stop the rotation, since motion can disrupt users
  • Inactive slides must be removed from the accessibility tree and the focus order using, for example, inert
  • The carousel should be marked as a <section> landmark with aria-roledescription="carousel" and aria-label to identify its purpose
  • Each slide should have aria-roledescription="slide"
