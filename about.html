About This Website

Purpose

This site is a quick-reference library of accessible HTML. It serves as an easily scannable guide for developers, designers and other interested parties looking to create working, semantic markup. It offers help for implementing universal web patterns, and expands on the accessibility features behind those patterns.

The patterns of this library follow the Web Content Accessibility Guidelines (WCAG) 2.2. They are designed to meet Level AA conformance, which is the standard required by most accessibility regulations and policies.

Features

Each pattern is demonstrated through a practical code example, accompanied by a list of the elements, attributes and keyboard interactions used to implement it. The scope is limited strictly to accessibility. To keep the instructions concise, the pattern's general functionality or visual design is not explained beyond what its accessibility features require.

The examples are written in plain HTML, CSS and JavaScript. They are intended to demonstrate accessibility concepts rather than serve as a production-ready design system. This makes the features shown a useful reference regardless of your technology stack.

Limitations

This library is not an official specification, a comprehensive accessibility guide or a substitute for understanding the underlying standards. It assumes at least a basic familiarity with accessibility concepts.

The library shows one way to implement accessible HTML. The examples aim to be easy to follow, reliable across browsers and programmatically correct. It is not the only correct approach, however, and implementations may vary depending on context and project requirements. Use the examples as a starting point or as a framework, not as a rigid specification.
