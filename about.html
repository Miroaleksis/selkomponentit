About This Website

Purpose

This site is a quick-reference library of accessible HTML. It serves as an easily scannable guide for developers, designers and other interested parties looking to create working, semantic code without unnecessary friction. It offers practical examples for implementing accessible web patterns, as well as expands on the elements and attributes behind those patterns.

The patterns in this library follow the Web Content Accessibility Guidelines (WCAG) 2.2. The examples are designed to meet Level AA conformance, which is the standard required by most accessibility regulations and policies.

Limitations

This library is not an official specification, a comprehensive accessibility guide or a substitute for understanding the underlying standards. It assumes at least a basic familiarity with accessibility concepts.

The examples on this site are written in plain HTML, CSS and JavaScript. They are intended to demonstrate accessibility concepts rather than serve as a production-ready design system. This makes them a useful reference regardless of your technology stack. The elements, attributes and keyboard interactions shown translate directly to any framework-based implementation.

The library shows one way to implement accessible HTML. The examples aim to be easy to follow, reliable across browsers and programmatically correct. It is not the only correct approach however and implementations may vary depending on context and project requirements. Use the examples as a starting point or as a framework, not as a rigid specification.
